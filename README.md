# A2ZCreate AI Studio

AI creative platform for generating posters and short scene-based videos.

## MVP Features

- AI script to scene breakdown
- Scene based video workflow (5-10 sec clips)
- Gemini AI integration ready
- ElevenLabs voice integration ready
- Poster generator workflow
- Brand kit system
- FFmpeg rendering pipeline planned

## Stack

- Next.js
- Tailwind CSS
- Gemini API
- ElevenLabs API
- FFmpeg

## Environment

Copy `.env.example` and add your API keys.

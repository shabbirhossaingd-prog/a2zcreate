# A2ZCreate Poster AI Flow

## Inputs

1. Inspiration Poster Upload
- Pinterest/reference design
- AI analyzes layout, color, typography, spacing

2. Product Upload
- Product image becomes main focus
- AI keeps product identity

3. Brand Assets
- Logo
- Brand colors
- Footer
- Website
- Contact info

4. Campaign Details
- Script
- Target audience
- Theme

## AI Process

Reference Poster
↓
Vision Analysis
↓
Extract Design Style
↓
Combine User Script + Product + Brand
↓
Generate New Unique Poster

The inspiration image is used as design direction, not copied directly.
